## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 안정 루틴 버전 또는 실험 상태 이력이 하나 이상 있고 원본 사건의 실제 시점을 조회할 수 있다. |
| 입력·행동 | 타임라인에서 루틴 확정·제품 변경·실험 상태·불편·Rescue·재시험을 시간순으로 보고 원본 상세를 연다. |
| 시스템 처리 | 기존 루틴·실험·관찰·Rescue 이력을 읽기 전용 타임라인으로 조합한다. 실제 발생 시각과 늦게 입력한 시각, 재시험 연결을 구분한다. |
| 사용자 결과 | 안정 루틴과 제품 사용이 어떻게 바뀌었고 어떤 실험 결과와 연결됐는지 되짚는다. |
| 핵심 규칙 | 원본과 확정 이력을 수정·복제하지 않는다. 당시 루틴과 실험 의도로 추가·교체·제외를 표시한다. 시간 순서를 인과관계로 표현하지 않는다. |
| 예외·복구 | 시점이 없거나 불확실한 사건에 임의 위치를 만들지 않는다. 현재 제품 정보로 과거 버전을 바꾸지 않는다. 피부 상태 그래프와 의학적 추세 분석은 포함하지 않는다. |
| 완료 기준 | 루틴·실험·불편·Rescue·변경·재시험 사건이 시간순으로 보인다. 각 원본으로 이동한다. 이후 정보 변경에도 과거 표현이 유지된다. 인과를 암시하는 연결을 만들지 않는다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
- 제품 의미가 달라지면 이 파일과 Story를 같은 변경에서 함께 수정한다.
