# F-01 계정·온보딩·AI 기억

## 목적

첫 가치 경험을 막지 않는 최소 개인화 정보를 얻고, AI가 기억하는 내용을 사용자가 통제하게 한다.

## 시작 조건과 입력

- 가입 직후이거나 사용자가 `내 정보 > AI가 기억하는 내용`을 연다.
- 온보딩 입력: 피부에서 요즘 신경 쓰이는 점, 선호 사용감, 피하고 싶은 조건, 제품을 고를 때 알고 싶은 점.
- 모든 문항은 자연어, 선택 입력이다.

## 정상 흐름

1. 가입 성공 후 온보딩 대화를 연다.
2. 한 화면에 한 질문을 보여주되 이전 답을 유지한다.
3. 사용자는 답하거나 건너뛴다.
4. AI가 문장을 요약하되 원문 의미를 추가하지 않는다.
5. 사용자가 확인하면 원문과 현재 요약을 저장한다.
6. 온보딩이 끝나면 현재 루틴 만들기로 이동한다.

## AI 기억

- 기억은 출처가 `온보딩`, `사용자 대화`, `사용자 수정` 중 무엇인지와 갱신 시각을 보여준다.
- 사용자는 항목별 수정·삭제를 할 수 있다.
- 삭제된 기억은 이후 AI 입력에서 제외한다.
- 루틴·사용 결과 같은 구조화된 이력은 이 화면의 자연어 기억과 별도로 보존한다.

## 예외

- AI 요약 실패: 원문을 그대로 저장하거나 사용자가 직접 짧게 고친다.
- 모든 질문 건너뜀: 빈 개인화로 계속하고 이후 제품 의견·추천에서 필요한 내용만 묻는다.
- 중복 가입·잘못된 비밀번호: 필드 가까이에 오류를 표시하고 입력값은 보존한다.

## 완료 조건

- 건너뛰기만으로도 홈까지 갈 수 있다.
- 한 사용자의 기억을 다른 계정에서 읽을 수 없다.
- 수정·삭제 후 다음 AI 요청에 옛 값이 포함되지 않는다.

연결 요구사항: ACC-01, ACC-02, ONB-01, ONB-02, MEM-01, MEM-02
