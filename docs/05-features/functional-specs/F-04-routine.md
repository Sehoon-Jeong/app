# F-04 루틴·AI 배치

## 목적

실제 사용하는 조합을 제품·시간대·순서·빈도로 저장하고, 변경할 때마다 당시 조건을 잃지 않는다.

## 만들기와 편집

1. 아침 또는 저녁을 고른다.
2. 내 화장품에서 제품을 추가한다. 목록 아래 `새 화장품 추가`는 등록 흐름으로 갔다가 같은 편집 화면으로 돌아온다.
3. 클렌징을 포함한 제품을 드래그해 순서를 정한다.
4. 빈도를 매일, 주 N회, 필요할 때 또는 미입력으로 둔다.
5. 제품 하나만 있어도 저장한다.
6. 저장할 때 기존 버전을 수정하지 않고 새 루틴 버전을 만든다.
7. 새 버전의 1일째는 사용자 시간대의 저장 날짜다.

사용자에게 “실제 사용 변경인지 기록 정정인지” 묻지 않는다. 현재 버전을 저장하면 항상 새 버전이다.

## AI 추천 순서로 배치하기

1. 현재 편집안을 AI 작업에 보낸다.
2. AI가 공식 사용법, 제형·사용 위치, 사용자의 메모와 시간대 맥락을 조사한다.
3. 사용법이 모호하거나 서로 충돌하면 사용자의 실제 사용 의도를 채팅으로 묻는다.
4. 서버가 제품 ID, 순서 중복, 빈도 형식과 모든 제품 포함 여부를 검증한다.
5. 사용자가 `이 순서로 배치`를 누르면 순서와 빈도를 편집안에 반영한다.
6. 사용자는 저장 전에 자유롭게 수정한다.

## 저장 후 AI 분석

- 화면은 저장 직후 `루틴 분석 중`을 보여준다.
- 서버는 루틴 저장과 AI job 생성을 먼저 커밋한다.
- AI 결과가 오면 전체 요약과 제품별 `이 루틴에서의 위치·역할·확인할 점·근거`를 표시한다.
- 실패해도 루틴과 7일 시작은 유효하다. 화면 상단 `AI 분석 다시 시도`를 제공한다.
- 분석은 새 루틴 버전, 카탈로그 사실 변경, 사용자 수동 재시도 때 실행한다.

## 예외와 완료 조건

- 현재 루틴 제품 삭제: 삭제를 막고 루틴에서 먼저 빼도록 이동한다.
- 빈 루틴 저장: 허용하지 않고 최소 한 제품을 요청한다.
- 중복 제품: 같은 시간대 중복을 막되 아침·저녁 동시 사용은 허용한다.
- 동시 저장 충돌: 최신 버전을 보여주고 편집안을 잃지 않은 채 병합 또는 다시 저장한다.
