## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 캐릭터·테마와 잠금 상태가 정의됐고 사용자가 LAB에 접근했다. |
| 입력·행동 | 목록을 미리 보고 해금된 캐릭터와 테마를 각각 선택한다. 잠긴 항목은 조건을 확인한다. |
| 시스템 처리 | 서버가 해금 상태를 검증하고 캐릭터·테마 선택을 독립적으로 저장한다. |
| 사용자 결과 | 즉시 적용된 LAB을 보고 재접속 뒤에도 마지막 선택을 유지한다. |
| 핵심 규칙 | 해금된 항목만 적용한다. 선택하지 않으면 기본 자산을 사용한다. 꾸미기는 추천·실험 결과에 영향을 주지 않는다. |
| 예외·복구 | 잠긴 항목의 직접 요청을 거부한다. 자산 로딩 실패가 관찰·실험·Archive를 막지 않는다. 캐릭터 대화와 피부 조언은 포함하지 않는다. |
| 완료 기준 | 해금 자산을 선택·즉시 적용·재접속 유지한다. 잠금 조건이 보인다. 기본 LAB이 동작한다. 자산 실패에도 핵심 흐름을 사용할 수 있다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
- 제품 의미가 달라지면 이 파일과 Story를 같은 변경에서 함께 수정한다.
