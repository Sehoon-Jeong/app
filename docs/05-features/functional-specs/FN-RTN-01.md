## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 로그인했고 계획·진행·보류 중인 실험이 없다. 카탈로그 제품 또는 확인한 개인 제품을 선택할 수 있다. |
| 입력·행동 | 피부 고민 또는 `잘 모르겠어요`, 아침·저녁 제품과 실제 사용 순서를 입력하고 현재 문제없이 쓴다는 사실을 직접 확인한다. |
| 시스템 처리 | 제품·시간대·순서 중복을 검증한다. 확인 전에는 초안으로 저장하고, 확인하면 이후 비교 기준이 되는 불변 루틴 버전을 만든다. |
| 사용자 결과 | 확정 시각과 아침·저녁 제품 구성을 확인하고 이후 추천·비교의 기준으로 사용한다. |
| 핵심 규칙 | 전체 루틴에는 제품이 하나 이상 있어야 한다. 같은 제품은 아침과 저녁에 각각 둘 수 있지만 같은 시간대에 중복할 수 없다. AI가 안정 여부를 판정하지 않는다. 열린 실험이 참조하는 루틴은 종료 전 바꿀 수 없다. |
| 예외·복구 | 제품을 찾지 못하면 직접 등록으로 이동한다. 안정 확인이 없으면 추천 기준으로 쓰지 않는다. 저장 실패 뒤에도 작성 중 입력을 유지한다. |
| 완료 기준 | 루틴을 저장·재조회한다. 확인 없는 입력은 안정 루틴이 되지 않는다. 중복과 잘못된 순서를 거부한다. 편집해도 과거 버전과 실험 참조가 보존된다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
- 제품 의미가 달라지면 이 파일과 Story를 같은 변경에서 함께 수정한다.
