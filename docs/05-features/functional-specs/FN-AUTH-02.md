## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 로그인한 사용자가 삭제 범위와 되돌릴 수 없다는 안내를 확인한다. |
| 입력·행동 | 비밀번호 재입력 또는 확인 문구로 삭제 의사를 확정한다. |
| 시스템 처리 | 새 쓰기를 잠그고 이미지·알림 구독·사용자 소유 데이터·개인 제품·인증 계정을 단계적으로 삭제한다. 이후 모든 개인 API에서 기존 JWT의 사용자 존재·잠금 검사를 실패시키고, 프론트엔드는 저장한 토큰을 삭제한다. 실패 단계는 재시도 가능한 비민감 상태로 남긴다. |
| 사용자 결과 | 삭제 직후부터 기존 계정과 개인 기록에 접근할 수 없다. |
| 핵심 규칙 | 삭제 대상은 인증된 사용자의 소유 데이터로 한정한다. 공용 카탈로그는 보존하고 개인 제품 초안은 삭제한다. 백업은 공급자 보존 주기 안에서 최대 30일 후 제거될 수 있음을 사전에 알린다. |
| 예외·복구 | 확인 실패나 취소 시 아무것도 삭제하지 않는다. 외부 파일 삭제가 실패해도 계정을 재활성화하지 않고 해당 단계부터 재시도한다. 반복 요청은 한 번의 삭제 작업으로 처리한다. |
| 완료 기준 | 개인 조회와 새 쓰기가 즉시 차단된다. 루틴부터 LAB·파일·알림까지 삭제된다. 기존 JWT와 이메일로 과거 기록에 접근할 수 없고 다른 사용자의 데이터는 영향받지 않는다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
- 제품 의미가 달라지면 이 파일과 Story를 같은 변경에서 함께 수정한다.
