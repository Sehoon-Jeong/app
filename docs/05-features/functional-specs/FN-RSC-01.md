## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 진행 또는 보류 중인 실험에서 사용자가 불편함을 선택했다. |
| 입력·행동 | 불편 유형·정도·부위·처음 인지한 시점, 필요한 경우 평소와 달랐던 일과 악화·도움 필요 여부를 기록한다. 제품 사용 중단 여부도 선택한다. |
| 시스템 처리 | 불편 기록과 Rescue를 중복 없이 만들고, 심함·악화·도움 필요 조건이면 고정 안전 안내를 먼저 표시한다. 중단 선택 시 실험을 보류하고 시점과 이유를 남긴다. |
| 사용자 결과 | 짧은 기록을 남기고 안전 안내와 최근 변경 확인으로 이어간다. |
| 핵심 규칙 | 불편 정도는 필수다. 생활 변화는 일반 관찰이 아니라 불편 시에만 선택적으로 묻고, 화장품 외 변수로서 근거 강도를 낮추는 데만 사용한다. 증상 원인·질환·치료법을 제시하지 않는다. |
| 예외·복구 | 생활 변화를 모르거나 답하지 않아도 불편 기록은 저장한다. 불편 유형은 질환 분류가 아니다. 심하거나 지속되는 불편에는 제품 사용 중단과 의료 전문가 확인을 안내한다. |
| 완료 기준 | 일반 관찰에 생활 질문이 반복되지 않는다. 정도 없는 불편 기록을 막는다. 안전 안내가 제품 분류보다 먼저 보인다. 실제 관찰·입력 시각을 구분한다. 중단 선택이 보류 이력에 남는다. |

## 연결 원칙

- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
