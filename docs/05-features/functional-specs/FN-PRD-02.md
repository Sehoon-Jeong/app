## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 제품 찾기 화면에서 카메라를 사용할 수 있거나 바코드 값을 직접 입력할 수 있다. |
| 입력·행동 | 카메라 권한을 허용해 바코드를 스캔하거나 값을 입력하고 일치 제품을 최종 확인한다. |
| 시스템 처리 | 확인된 카탈로그 고유 식별자와 정확히 비교한다. 하나만 일치하면 제품을 제시하고 중복 식별자면 자동 선택하지 않는다. |
| 사용자 결과 | 정확히 일치하는 제품을 루틴 또는 실험 후보에 추가한다. |
| 핵심 규칙 | 유사 값이나 부분 일치로 제품을 추측하지 않는다. 사용자 확인 전 자동 추가하지 않는다. 바코드 원문을 행동 분석용으로 남기지 않는다. |
| 예외·복구 | 카메라 거부·인식 실패·미일치 시 제품명 검색과 직접 등록을 제공한다. 중복 식별자는 운영 확인 대상으로 남긴다. |
| 완료 기준 | 정확한 단일 일치만 보여준다. 미일치와 중복에서 자동 연결하지 않는다. 모든 실패 상태에서 검색·직접 등록을 계속할 수 있다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
- 제품 의미가 달라지면 이 파일과 Story를 같은 변경에서 함께 수정한다.
