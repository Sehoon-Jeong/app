# F-07 기록·알림

## 루틴 기록

- 기본 화면은 최신순 타임라인이다.
- 항목에는 버전, 사용 기간, 생성 이유(`직접 변경`, `Rescue 제안 적용`), 아침·저녁 제품 수, 결과를 표시한다.
- 상세에는 각 시간대의 제품·순서·빈도, AI 분석 상태, 7일 결과, 연결 Rescue를 표시한다.
- 사용자는 두 버전을 골라 추가·삭제·순서 이동·빈도 변경을 비교한다.
- 과거 버전은 수정하지 않는다.

## 제품에서 기록으로 이동

- 제품 상세의 `사용 기록`은 해당 제품이 포함된 루틴 버전을 최신순으로 보여준다.
- 결과가 루틴 전체에 대한 것인지 조기 기록인지 명시한다.
- 제품 단독 결과가 없으면 없다고 표시한다.

## 홈 우선순위

한 번에 가장 중요한 행동 하나를 다음 순서로 보여준다.

1. 사용자가 진행 중인 Rescue 대화
2. 기한이 지난 7일 결과
3. 오늘 도래한 7일 결과
4. 실패한 루틴 AI 분석 재시도
5. 진행 중인 7일 현황
6. 안정 루틴을 쓰는 경우 제품 의견·추천 진입
7. 루틴이 없으면 첫 루틴 만들기

Rescue에서 기록만 남겼으면 진행 중 현황에 `Rescue 기록 있음 · 루틴 변경 없음`을 표시한다.

## 앱 안 알림

- 종류: 7일 결과 도래, 연장 결과 도래, 영수증 OCR 완료, 추천·제품 조사·Rescue 분석 완료, AI 작업 실패.
- 읽음/안 읽음과 연결 화면을 저장한다.
- 푸시·이메일·문자와 브라우저 알림 권한은 사용하지 않는다.
- 알림 읽음은 사용 결과가 아니다.

## 완료 조건

- 버전 비교가 실제 저장된 스냅샷만 사용한다.
- 연결 리소스가 삭제되면 알림은 안전한 빈 상태로 열린다.
- 같은 사건에 중복 알림을 만들지 않는다.

연결 요구사항: HIS-01~03, NOT-01~02, OBS-01
