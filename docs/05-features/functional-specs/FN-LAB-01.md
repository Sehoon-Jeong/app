## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 실험에 필수 관찰 퀘스트가 생성됐다. |
| 입력·행동 | 필수 관찰을 저장하고 실험 상태, 관찰 완료 수·전체 수와 남은 행동을 확인한다. 최종 결과를 남기면 실험 완료 연구를 확인한다. |
| 시스템 처리 | 관찰 완성도는 완료한 필수 퀘스트 수/전체 수로 계산하고, 실험 완료는 최종 결과 저장 여부로 별도 계산한다. |
| 사용자 결과 | 퀘스트를 놓쳐도 실험을 끝낼 수 있고, 자신이 실제로 남긴 기록의 완성도를 LAB에서 이해한다. |
| 핵심 규칙 | 건너뜀은 관찰 완료로 세지 않지만 실험 완료를 막지 않는다. 관찰 수정·재전송으로 보상을 중복 생성하지 않는다. 불편·목적 체감의 방향이 보상량을 바꾸지 않는다. |
| 예외·복구 | 취소 실험은 진행 이력만 남기고 완료 연구 보상을 만들지 않는다. 로그인·접속·알림 클릭·화면 체류는 진행도와 보상을 올리지 않는다. |
| 완료 기준 | 필수·선택·건너뜀 조합에 맞는 관찰 완성도가 나온다. 건너뜀이 있어도 결과 저장 후 완료 연구가 생긴다. 실험 완료와 100% 관찰을 같은 값으로 표시하지 않는다. |
