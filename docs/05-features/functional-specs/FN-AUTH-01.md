## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 로그인하지 않은 사용자가 처음 가입하거나 기존 계정으로 돌아온다. |
| 입력·행동 | 이메일과 비밀번호로 가입 또는 로그인하고, 필요하면 로그아웃한다. |
| 시스템 처리 | 이메일을 정규화하고 비밀번호는 단방향 해시로 저장한다. 15분 access JWT와 7일 회전형 refresh session을 발급·검증한다. 로그인 후 서버에서 현재 안정 루틴과 열린 실험을 조회한다. |
| 사용자 결과 | 신규 사용자는 안정 루틴 등록으로, 기존 사용자는 진행 중인 실험 또는 홈으로 이동한다. 재접속해도 자신의 기록을 이어간다. |
| 핵심 규칙 | 데이터 소유자는 인증 정보로 결정한다. 프론트엔드가 보낸 사용자 ID를 신뢰하지 않는다. 인증 실패 응답과 로그에 비밀번호·JWT·계정 존재 여부를 노출하지 않는다. |
| 예외·복구 | 잘못된 형식과 자격 증명은 수정 가능한 오류로 안내한다. access JWT 만료 시 refresh session으로 한 번 연장하고, 둘 다 만료되면 기록을 유지한 채 재로그인을 요청한다. 소셜 로그인·비밀번호 재설정은 MVP 밖이다. |
| 완료 기준 | 가입 후 안정 루틴 등록에 도달한다. 기존 사용자의 루틴과 열린 실험이 복원된다. 로그아웃 후 개인 API 접근이 차단된다. 다른 사용자의 식별자로 기록을 조회할 수 없다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
