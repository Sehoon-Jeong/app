# F-02 카탈로그·내 화장품

## 목적

사용자가 제품 기능을 직접 입력하지 않고도 실제 국내 판매 제품 버전을 찾아 자신의 보유 목록에 넣게 한다.

## 제품명 검색

1. 브랜드 또는 제품명을 입력한다.
2. 서버는 한국 제품 카탈로그에서 브랜드, 정식 제품명, 용량·옵션, 대표 이미지와 버전 상태를 반환한다.
3. 사용자가 하나를 고르면 제품 상세를 확인한다.
4. `내 화장품에 추가`를 누르면 `미사용 화장품`에 들어간다.
5. 현재 루틴에는 자동으로 들어가지 않는다.

## 영수증 OCR

1. 사용자가 영수증 이미지를 올린다.
2. 원본을 저장하고 비동기 OCR 작업을 만든다.
3. AI는 브랜드·제품명·용량 후보와 원문 위치만 반환한다.
4. 서버가 후보를 카탈로그 제품 버전과 연결한다.
5. 사용자는 각 행의 제품과 용량을 확인·교체·제외한다.
6. 확정한 모든 제품을 미사용 화장품으로 추가한다.

## 버전 불확실

- 사용자가 버전을 고르게 하지 않는다.
- 포장, 구매 시기, 용량으로 하나를 확정할 수 없으면 `버전 확인 중`으로 등록한다.
- 해당 항목은 보유 목록과 메모에는 쓰지만 제품 의견, 추천, 루틴 AI 분석과 Rescue의 제품 사실 근거에서는 제외한다.
- 해커톤에서는 카탈로그 검수 요청만 접수한다.

## 제품 상세

- 표시: 제품 정체성, 제조사 설명, 사용법, 표시 전성분, 관련 근거, 참고 가격·판매처, 확인 시각.
- AI에게 물을 수 있는 내용: 내 루틴에서의 위치, 공식 사용법, 관련 성분 근거, 내 과거 기록과의 연결.
- 메모는 사용자가 저장하며 요청한 분석에만 포함한다.
- 제품 삭제는 현재 루틴에 있으면 먼저 루틴 편집을 요구한다.

## 예외와 완료 조건

- OCR 실패 또는 미일치: 입력값을 잃지 않고 제목 검색으로 전환한다.
- 검색 결과 없음: 검수 요청을 남기고 사용자가 입력한 이름을 표시한다.
- 같은 제품 재등록: 기존 항목을 보여주고 중복 등록 여부를 확인한다.
- 영수증 원본은 MVP에서 영구 보관하며 계정 영구 삭제 시 함께 삭제한다.
