# F-06 AI Rescue

## 목적

불편이 생겼을 때 진단이나 범인 확정 없이 기록된 변경과 외부 근거를 이용해 확인 순서와 다음 루틴을 정한다.

## 대화 원칙

- 이전 메시지는 삭제하지 않고 카카오톡처럼 아래로 이어진다.
- 진행률이나 설문 단계 번호를 표시하지 않는다.
- 자유 입력이 기본이고 빠르게 답할 수 있는 경우에만 선택 버튼을 함께 준다.
- AI는 이미 저장된 정보를 다시 묻지 않는다. 사용자는 언제든 사실을 수정한다.

## 정상 흐름

1. 사용자가 불편을 자유 문장으로 말한다.
2. AI가 표현을 구조화하고 발생 시점, 실제 사용, 최근 생활·제품 변화, 심한 정도 중 빈 정보만 묻는다.
3. 심각하거나 빠르게 악화된다는 답이면 제품 순위를 중단하고 전문가 확인을 제안한다.
4. 서버가 마지막 안정 루틴과 현재 루틴의 제품·순서·빈도 차이를 계산한다.
5. AI가 변경 목록을 보여주고 사용자의 누락·틀린 시점을 고친다.
6. AI가 제품 공식 정보, 완제품 인체 연구, 관련 원료 연구, 사용 시점과 개인 기록을 검색한다.
7. 서버가 인용 출처, 제품 버전, 사용자 기록 소유권과 제안 루틴 형식을 검증한다.
8. AI가 확인 우선순위를 보여준다. 각 항목에는 `먼저 보는 이유`, `반대 근거`, `모르는 점`이 있다.
9. AI가 제외·유지할 제품, 아침/저녁, 순서와 빈도를 포함한 다음 루틴 하나를 제안한다.
10. 사용자는 `이 루틴으로 시작` 또는 `기록만 남기기`를 고른다.

## 분기

### 다음 루틴 적용

- 현재 루틴과 독립된 새 버전을 만든다.
- 새 루틴은 DAY 1부터 7일 결과 흐름을 그대로 사용한다.
- 이전 Rescue의 순위와 결과는 다음 분석의 보조 근거가 된다.

### 기록만 남김

- Rescue 대화와 분석을 저장하되 현재 루틴과 7일 일정은 바꾸지 않는다.
- 홈에는 `Rescue 기록 있음 · 루틴 변경 없음`을 보여준다.

### 안정 루틴 없음

- 기준점이 약하다고 먼저 알린다.
- 개인 기록에서 가장 오래 변경 없이 사용했고 불편 기록이 없는 제품을 찾아 최소 루틴을 제안할 수 있다.
- 제품 의심 순위의 확신을 낮추고 근거 부족을 표시한다.

### 현재 루틴 없음

- 일반적인 안전 안내와 사용자의 자유 기록만 저장한다.
- 제품별 의심 순위와 개인화 루틴은 만들지 않는다.

## 금지와 완료 조건

- `원인`, `범인`, `알레르기 진단`, 확률 퍼센트를 출력하지 않는다.
- 사용자가 선택하기 전에 제품을 자동 삭제하거나 루틴을 바꾸지 않는다.
- AI 실패 시 변경 목록과 사용자의 원문은 보존하고 재시도한다.
- 각 주장에 출처 또는 개인 기록이 연결되고, 검색하지 못한 내용은 정보 부족으로 남는다.
