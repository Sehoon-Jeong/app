## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 로그인했고 제품명이 보이는 영수증 또는 주문 내역 이미지가 있다. |
| 입력·행동 | AI 구조화를 요청하고 브랜드·제품명 후보를 수정·제외한 뒤 필요한 항목만 확정한다. |
| 시스템 처리 | 제품명 후보와 이미지 안 행 위치만 구조화한다. 확인 가능한 카탈로그 일치를 제안하되 자동 연결하지 않는다. 원본은 확인 후 삭제하고 미완료 원본도 7일 이내 삭제한다. |
| 사용자 결과 | 선택한 항목만 카탈로그 제품 또는 개인 제품 초안으로 등록한다. |
| 핵심 규칙 | 쇼핑몰·결제 시스템과 연동하지 않는다. 금액·주문번호·주소·연락처를 저장·분석하지 않는다. AI는 요청한 이미지의 최소 범위만 처리하며 결과는 사용자 확인 전 초안이다. |
| 예외·복구 | 읽지 못한 행은 제외하고 일부 항목만 등록할 수 있다. AI 거부·실패·30초 초과 시 입력을 유지하고 재시도·취소·직접 입력으로 전환한다. |
| 완료 기준 | 후보별 확인·수정·제외가 가능하다. 확정 항목만 등록한다. 개인정보가 도메인·로그에 남지 않는다. 이미지 보존 기한을 지킨다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
- 제품 의미가 달라지면 이 파일과 Story를 같은 변경에서 함께 수정한다.
