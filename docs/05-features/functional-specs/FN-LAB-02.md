## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 최종 결과를 확정했고 실험을 완료 상태로 바꿀 수 있다. |
| 입력·행동 | 최종 결과를 저장하고 완료 화면과 연구실에서 새 연구 기록을 확인한다. |
| 시스템 처리 | 완료 실험 하나에 원래 실험과 당시 관찰 완성도를 참조하는 연구 기록 하나를 만든다. 결과 저장·완료 전환·기록 생성을 중복 안전한 한 작업으로 처리한다. |
| 사용자 결과 | 불편·목적 체감이나 건너뜀과 관계없이 결과를 남긴 완료 연구 하나가 자신의 연구실에 쌓인다. |
| 핵심 규칙 | 세 결과의 방향과 관찰 완성도가 연구 획득 여부나 기본 보상을 바꾸지 않는다. 연구실 성장은 잘 맞은 제품 수가 아니라 완료한 실험 수다. 결과 복사본을 만들지 않는다. |
| 예외·복구 | 취소 또는 결과 없는 실험에는 기록을 만들지 않는다. 재전송·새로고침·네트워크 재시도에도 중복 생성하지 않는다. 실패 결과를 감점하지 않는다. |
| 완료 기준 | 허용된 모든 결과 조합과 관찰 완성도에서 기록 하나를 만든다. 취소·결과 없음에는 만들지 않는다. 연구 기록에서 원래 실험과 완성도를 확인한다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
- 제품 의미가 달라지면 이 파일과 Story를 같은 변경에서 함께 수정한다.
