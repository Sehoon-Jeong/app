## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 진행 또는 보류 실험에 관찰 퀘스트가 있고 사용자 시간대가 설정됐다. |
| 입력·행동 | 예정·오늘·놓친 퀘스트를 보고 지금 기록하거나 기억하지 못한 항목을 건너뛴다. |
| 시스템 처리 | 사용자 현지 날짜로 예정·오늘·놓침·완료·중지 상태를 계산한다. 완료 퀘스트는 할 일에서 제거하되 이력에 보존한다. |
| 사용자 결과 | 앱을 열면 지금 필요한 관찰과 다음 예정일을 바로 확인한다. |
| 핵심 규칙 | 앱 안 목록이 관찰 안내의 기준이며 외부 알림에 의존하지 않는다. 놓침을 비난하지 않고 기록과 건너뛰기를 모두 제공한다. |
| 예외·복구 | 실제 관찰 시각과 입력 시각을 구분한다. 건너뜀은 완료율에 넣지 않는다. 시간대가 바뀌어도 절대 시각은 유지한다. 알림이 없어도 전체 기능이 동작한다. |
| 완료 기준 | 예정 전·당일·경과 상태가 시간대에 맞는다. 완료·건너뜀·중지 결과가 목록과 일치한다. 중복 할 일이 생기지 않는다. 빈 상태의 이유와 다음 행동이 보인다. |

- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
