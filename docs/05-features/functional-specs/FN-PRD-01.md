## 기능 동작

| 항목 | 명세 |
| --- | --- |
| 시작 조건 | 로그인했고 검색에서 제품을 찾지 못했거나 직접 등록을 선택했다. |
| 입력·행동 | 브랜드·제품명·종류를 입력하고, 선택적으로 전성분 사진의 AI 구조화를 요청한 뒤 추출 후보를 수정·제외·확정한다. |
| 시스템 처리 | 개인에게만 보이는 제품 초안을 만든다. 요청한 경우에만 최소 이미지로 성분 후보를 구조화하며 확인된 값만 비교 근거로 저장한다. 원본 이미지는 확인 후 삭제하고 미완료 원본도 7일 이내 삭제한다. |
| 사용자 결과 | 카탈로그에 없는 제품을 자신의 안정 루틴 또는 실험 후보에 사용할 수 있다. |
| 핵심 규칙 | 개인 초안은 운영 확인 전 공용 검색·추천에 노출하지 않는다. AI 결과는 초안이며 읽지 못한 성분을 채우지 않는다. 이메일·사용자 ID·인증정보·무관한 기록을 AI에 보내지 않는다. |
| 예외·복구 | 사진 없이 직접 입력할 수 있다. AI 거부·실패·30초 초과 시 입력을 유지하고 재시도·취소·직접 입력으로 전환한다. 일부만 확인됐으면 나머지는 정보 부족으로 남긴다. |
| 완료 기준 | 개인 제품 초안을 생성한다. 추출값을 항목별로 검토한다. 미확정 값은 추천 근거가 되지 않는다. 이미지 보존 기한과 비공개 원칙을 지킨다. |

## 연결 원칙

- 사용자 흐름과 완료 조건의 상세 원본은 위 GitHub Story다.
- 요청·응답은 [OpenAPI](../../api/README.md), 저장 구조는 [데이터 사전](../../06-data-model/data-dictionary.md)에서 확인한다.
- 제품 의미가 달라지면 이 파일과 Story를 같은 변경에서 함께 수정한다.
