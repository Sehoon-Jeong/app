# F-03 AI 제품 탐색 요구사항

[Feature #159](https://github.com/skn-labs/app/issues/159)

## P0

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| EXP-01 | 사용자는 궁금한 제품을 골라 내 사용 경험과 비교하거나 자연어로 다음 후보를 묻는다. | 코덕의 반복 탐색이 제품 순환의 입구다. |
| EXP-02 | AI는 확인된 제품 사실, 현재 루틴, 관련 경험의 평가·태그와 패턴 후보를 서로 구분해 사용한다. 메모 원문은 사용자가 명시적으로 요청하지 않으면 보내지 않는다. | 일반 정보와 개인 근거를 혼동하지 않고 최소 전송을 지킨다. |
| EXP-03 | 결과는 닮은 경험·다른 점·현재 조합에서 볼 점·반대 기록·정보 부족을 보여준다. | 좋다/나쁘다 판정 없이 비교 가능한 가치를 준다. |
| EXP-04 | AI 답변은 제품 정보·루틴·내 경험·패턴 중 실제로 연결한 근거의 종류와 건수를 보여준다. | 근거 없는 설명과 개인 기록 기반 설명을 구분한다. |
| EXP-05 | 제품 질문은 공통 AI 채팅으로 이어지고 진입 맥락이 자동 전송된다. 입력창과 예상 답변 최대 3개를 항상 제공한다. 추천 답변의 검증된 카탈로그 제품은 답변 아래 카드로 표시하며 누르면 해당 제품 상세로 이동한다. | 화면마다 다른 챗봇을 만들지 않고 탐색 결과를 실제 제품 확인으로 연결한다. |
| EXP-06 | 제품을 내 화장품에 넣어도 현재 루틴에는 자동 추가하지 않는다. | 탐색·보유·실제 사용을 분리한다. |
