# F-03 제품 의견·추천 요구사항

[Feature 명세 #159](https://github.com/sksksksksksss/service/issues/159)

## P0 · 최소 제품 의견

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| OPN-01 | 사용자는 외부에서 본 한 제품을 골라 `이거 사볼까?` 의견을 요청한다. | 핵심 순환의 대표 진입점이다. |
| OPN-02 | 최소 제품 의견은 현재 목적, 현재·안정 루틴과 과거 루틴 결과를 사용한다. P0에서 없는 외부 제품 사실은 `정보 부족`으로 남긴다. | 일반 AI 설명과 개인 기록 재사용을 구분한다. |
| OPN-03 | 결과는 고려할 이유, 겹치는 이유, 현재 목적과의 거리 또는 정보 부족 중 하나와 근거·반대·불확실성을 보여준다. 적합·안전·효능을 보장하지 않는다. | 좋다/나쁘다 판정 없이 행동 가능한 결론을 준다. |
| OPN-06 | 사용자가 `샀어요`를 선택하면 정확한 제품 또는 입력 이름을 내 화장품에 추가하고 루틴에는 자동 반영하지 않는다. | 구매 전 판단을 이후 사용 기록에 연결한다. |

## P1 · 제품 후속 채팅

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| OPN-04 | 사용자는 제품 의견에서 후속 질문하고 AI는 같은 입력 snapshot과 검증된 근거를 이어서 사용한다. | 정적 결과 뒤 실제 궁금증을 해결한다. |

## P2 · 제품 발견과 구매 편의

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| REC-01 | 사용자는 원하는 변화를 자연어로 말하고 필요한 추가 질문에 답한다. | 외부에서 본 한 제품 의견과 다른 탐색 문제다. |
| REC-02 | AI는 실제 국내 제품 후보 0~5개를 찾고 서버가 버전·근거·중복·제외 조건을 검증한다. | 광범위 카탈로그와 검색 품질이 필요하다. |
| REC-03 | 후보마다 추천·망설임·정보 부족·관찰할 점을 표시한다. | 추천 기능과 함께 검증한다. |
| REC-04 | 추천은 적합 확률·효능·안전·인기 순위가 아니다. | 추천 기능의 안전 경계다. |
| OPN-05 | 비슷한 제품과 찜 기능을 제공하고 보유 제품을 구분한다. | 핵심 개인화 의견과 다른 탐색·보관 유틸리티다. |
