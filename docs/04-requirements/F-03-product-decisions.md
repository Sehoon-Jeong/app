# F-03 AI 제품 탐색 요구사항

[Feature #159](https://github.com/sksksksksksss/skn-app/issues/159)

## P0

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| EXP-01 | 사용자는 궁금한 제품을 골라 내 사용 경험과 비교하거나 자연어로 다음 후보를 묻는다. | 코덕의 반복 탐색이 제품 순환의 입구다. |
| EXP-02 | AI는 확인된 제품 사실, 현재 루틴, 관련 경험 원문과 패턴 후보를 서로 구분해 사용한다. | 일반 정보와 개인 근거를 혼동하지 않는다. |
| EXP-03 | 결과는 닮은 경험·다른 점·현재 조합에서 볼 점·반대 기록·정보 부족을 보여준다. | 좋다/나쁘다 판정 없이 비교 가능한 가치를 준다. |
| EXP-04 | 사용자는 결과 근거에서 연결된 원본 경험과 제품 출처로 이동한다. | AI 문장을 검증할 수 있게 한다. |
| EXP-05 | 제품 질문은 공통 AI 채팅으로 이어지고 진입 맥락이 자동 전송된다. 입력창과 예상 답변 최대 3개를 항상 제공한다. | 화면마다 다른 챗봇을 만들지 않는다. |
| EXP-06 | 제품을 내 화장품에 넣어도 현재 루틴에는 자동 추가하지 않는다. | 탐색·보유·실제 사용을 분리한다. |
