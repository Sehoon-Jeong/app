# F-04 루틴 요구사항

[Feature 명세 #160](https://github.com/sksksksksksss/service/issues/160)

## P0 · 직접 루틴과 불변 버전

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| RTN-01 | 루틴은 제품, 아침/저녁, 바르는 순서와 실제 빈도를 가진 불변 버전이다. 한 버전은 한 번의 실제 사용기간이며 클렌징도 포함한다. | Rescue가 당시 조건을 복원하려면 덮어쓸 수 없다. |
| RTN-02 | 제품 하나로도 루틴을 시작할 수 있고 빈도 입력을 건너뛰면 `매일` 기본값을 사용자가 확인한다. | 진입은 단순하게 유지하되 비교 가능한 빈도를 남긴다. |
| RTN-03 | 제품·순서·시간대·빈도 변경을 저장하면 기존 루틴을 보존하고 새 ACTIVE 버전과 새 DAY 7 schedule을 만든다. 과거 버전을 다시 활성화하지 않는다. | 변경 전후와 실제 사용기간을 분리한다. |
| RTN-04 | 사용자는 내 화장품을 추가·제거하고 아침/저녁, 순서와 빈도를 직접 편집한다. 목록에 없는 제품은 등록 후 같은 편집안으로 돌아온다. | AI 순서 추천 없이도 핵심 루틴 사실을 기록한다. |

## P1 · AI 배치와 설명

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| RTN-05 | AI는 공식 사용법과 현재 편집안을 이용해 제품 집합을 바꾸지 않는 순서·빈도 후보를 제안한다. | 핵심 기록 이후의 즉시 가치를 강화한다. |
| RTN-06 | 사용자가 적용을 누를 때만 AI 순서·빈도를 편집안에 반영하고 저장 전 다시 수정할 수 있다. | AI 제안을 실제 사용 사실로 자동 확정하지 않는다. |
| RTN-07 | 루틴 저장 후 루틴·제품별 AI 설명을 비동기로 만들며 실패해도 루틴과 DAY 7은 유지한다. | 설명 기능과 기록 기능의 장애를 분리한다. |
| RTN-08 | 각 제품의 현재 위치·확인된 역할·정보 부족과 근거를 표시한다. | 루틴 전체뿐 아니라 제품별 맥락을 이해한다. |
