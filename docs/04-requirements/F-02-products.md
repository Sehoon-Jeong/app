# F-02 카탈로그·내 화장품 요구사항

[Feature #158](https://github.com/sksksksksksss/skn-app/issues/158)

## P0

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| PRD-01 | 사용자는 제품명 검색 또는 직접 이름으로 내 화장품에 추가한다. 등록만으로 루틴은 바뀌지 않는다. | 입력 부담을 낮추고 실제 사용 여부를 분리한다. |
| PRD-02 | 내 화장품은 전체·현재 루틴·아직 안 써봄으로 찾고, 각 제품에서 연결된 경험 수와 원문으로 이동한다. | 보유 상태보다 제품과 경험의 연결을 먼저 이해한다. |
| PRD-03 | 사용자는 제품별 메모를 경험 기록으로 전환하거나 단순 메모로 남길 수 있다. AI 사용 여부를 명시한다. | 비정형 기록의 의미와 사용 권한을 구분한다. |
| CAT-01 | 버전이 확인되지 않은 제품도 이름과 사용 사실은 남기되 공식 사실·성분 근거에는 쓰지 않는다. | 기록을 막지 않고 거짓 제품 사실을 피한다. |

## P1

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| CAT-02 | 브랜드·제품명·시장·용량·처방·패키지 단서가 같은 출시판을 식별한다. | 다른 버전의 정보가 섞이지 않게 한다. |
| CAT-03 | 제품 사실은 확인 당시 외부 snapshot을 참조하고 출처 종류·시각·원문 hash를 보존한다. | 과거 AI 설명을 재검증한다. |
| PRD-04 | 제품 삭제 후에도 과거 경험의 표시 이름과 참조 무결성을 보존한다. | 개인 이력을 끊지 않는다. |

## P2

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| PRD-05 | 영수증 OCR 후보는 사용자가 확인한 제품만 내 화장품에 추가한다. | 제품 검색 불편이 확인된 뒤 제공한다. |
| CAT-04 | 가격·판매처·확인 시각을 표시하되 AI 판단 순위에는 쓰지 않는다. | 구매 편의와 추천 독립성을 분리한다. |
