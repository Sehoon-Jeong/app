# F-02 카탈로그·내 화장품 요구사항

[Feature 명세 #158](https://github.com/sksksksksksss/service/issues/158)

## P0 · 최소 제품 등록

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| PRD-01 | 사용자는 큐레이션된 제품을 제품명으로 찾거나 이름을 직접 입력해 내 화장품에 추가한다. 등록만으로 현재 루틴은 바뀌지 않는다. | 제품 등록 편의보다 실제 제품과 사용 기록 연결이 먼저다. |
| CAT-03 | 정확한 버전을 확인하지 못한 제품도 이름과 사용 사실은 기록할 수 있지만 성분·기능·사용법을 AI 사실 근거로 사용하지 않는다. | 입력을 막지 않으면서 모르는 제품 사실을 만들지 않는다. |

## P1 · 카탈로그와 제품 관리

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| CAT-01 | 국내 판매 스킨케어·클렌징·선케어의 실제 출시판을 카탈로그로 관리한다. | 테스트 제품을 넘어 실제 사용자 제품을 안정적으로 연결한다. |
| CAT-02 | 제품은 브랜드, 이름, 처방·용량·포장·시장 단서가 같은 출시판으로 식별한다. | 서로 다른 버전의 공식 정보가 섞이지 않게 한다. |
| CAT-04 | 제품 사실은 적용 출시판과 확인 당시 evidence snapshot을 참조한다. | 나중에 같은 설명을 재검증한다. |
| CAT-05 | 제조사·브랜드, 정부·규제기관, 공식 DB·원 논문만 근거로 사용하고 리뷰·커뮤니티는 제외한다. | 인기와 제품 사실을 분리한다. |
| PRD-04 | 사용자는 제품별 짧은 메모를 남기고 명시적으로 허용한 AI 요청에만 포함한다. | 비정형 사용 맥락을 통제 가능하게 보존한다. |
| PRD-05 | 내 화장품을 미사용, 현재 루틴, 마지막 안정 루틴 관계로 묶어 보여준다. | 저장 제품이 어떤 맥락에 있는지 이해한다. |
| PRD-06 | 사용자는 현재 루틴 연결을 먼저 정리한 뒤 내 화장품을 삭제한다. 과거 루틴 참조는 보존한다. | 현재 상태와 과거 기록을 함께 지킨다. |

## P2 · 입력과 구매 편의

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| PRD-02 | 영수증 OCR은 브랜드·제품명·용량 후보를 읽고 사용자가 확정한다. | 제품명 검색·직접 입력의 불편이 검증되지 않았다. |
| PRD-03 | 영수증 확정 제품은 내 화장품에만 넣고 루틴에 자동 추가하지 않는다. | OCR과 함께 구현한다. |
| CAT-06 | 가격·판매처·확인 시각을 참고로 표시하되 판단 순위에는 쓰지 않는다. | 구매 전환과 제휴 BM을 검증할 때 추가한다. |
