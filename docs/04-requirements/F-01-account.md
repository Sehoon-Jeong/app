# F-01 계정·개인화 요구사항

[Feature 명세 #157](https://github.com/sksksksksksss/service/issues/157)

## P0 · 계정

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| ACC-01 | 공개 MVP 사용자는 이메일로 가입·로그인하고 자기 데이터에만 접근한다. 클릭 프로토타입은 고정 테스트 계정으로 대체할 수 있다. | 개인 경험이 다른 사용자와 섞이면 모든 판단이 무효다. |
| ACC-02 | 사용자는 계정과 연결 기록의 영구 삭제를 요청할 수 있다. | 실제 사용자의 개인 기록을 받는 순간 필요한 통제다. |

소유권과 비밀값 요구사항은 [F-08 AI·보안·운영](./F-08-ai-operations.md)의 SEC-01~02를 함께 적용한다.

## P2 · 선택형 온보딩과 AI 기억

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| ONB-01 | 피부 고민, 사용감, 피하고 싶은 조건과 제품 선택 질문을 자연어로 묻는다. | 현재 루틴과 결과만으로 P0 개인화를 시작할 수 있다. |
| ONB-02 | 모든 질문에 `잘 모르겠어요`·건너뛰기·나중 수정을 제공한다. | 범용 온보딩을 만들 때 함께 구현한다. |
| MEM-01 | 사용자가 확인한 범용 자연어 맥락을 저장·조회한다. | 구조화된 제품·루틴·결과가 먼저 기억 역할을 한다. |
| MEM-02 | 사용자는 AI 기억을 수정·삭제한다. | 범용 기억을 실제로 사용할 때 필요하다. |
