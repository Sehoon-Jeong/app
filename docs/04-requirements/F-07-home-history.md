## P1 · 전체 이력과 앱 안 알림

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| HIS-01 | 사용자는 루틴 버전, schedule·결과와 연결 Rescue를 시간순으로 본다. | 개인 데이터가 쌓였음을 확인한다. |

| NOT-01 | 앱 안 알림함은 due assessment와 사용자가 시작한 AI 작업 완료·실패만 알린다. 푸시·문자·이메일은 사용하지 않는다. | 결과 회수와 긴 작업 복귀를 돕는다. |
| NOT-02 | 알림 읽음은 결과 제출·불편 없음·AI 결과 확인으로 해석하지 않는다. | 전달 상태와 사용자 사실을 분리한다. |
