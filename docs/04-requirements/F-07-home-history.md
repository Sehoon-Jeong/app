# F-07 홈·기록·패턴 요구사항

[Feature #163](https://github.com/sksksksksksss/service/issues/163)

## P0

| ID | 요구사항 | 이유 |
| --- | --- | --- |
| HOME-01 | 홈은 `현재 사용 경험`, `새로 연결된 내 패턴`, `빠른 기록`, `다음 탐색` 순으로 보여준다. 7일 진행률은 현재 경험 안의 보조 정보다. | 제품 정체성을 일정 관리가 아니라 경험 연결로 보여준다. |
| HIS-01 | 사용자는 제품·루틴·시점이 연결된 경험 원문을 시간순으로 본다. | 기록이 실제로 쌓였음을 이해한다. |
| PAT-01 | AI 패턴은 두 개 이상의 관련 경험, 근거 건수, 연결 원문, 반대 기록과 불확실성을 가진다. | 그럴듯한 AI 성격 테스트가 되지 않게 한다. |
| PAT-02 | 근거가 한 건이면 패턴이 아니라 해당 경험의 관찰로 표시한다. | 희소한 개인 데이터를 과장하지 않는다. |
| PAT-03 | 사용자는 패턴에서 원본 경험으로 이동하고 관련 없음 피드백을 남길 수 있다. | 설명 가능성과 잘못된 연결 수정을 보장한다. |
| PAT-04 | 확정 또는 유효한 패턴 후보는 다음 제품 탐색과 AI 질문에서 원본 근거와 함께 다시 사용한다. | 기록 앱과 구분되는 폐쇄형 순환을 완성한다. |
