# 제품 규칙과 AI 경계

## 용어

- **내 화장품**: 사용자가 등록한 제품 전체다. 미사용 제품과 루틴 제품을 포함한다.
- **루틴**: 제품 조합, 아침/저녁, 순서, 빈도를 한 시점의 버전으로 저장한 것이다.
- **현재 루틴**: 사용자가 지금 쓴다고 마지막으로 저장한 루틴 버전이다.
- **안정 루틴**: 기록과 비슷하게 7일 사용했고 전반적인 불편이 없었다고 확인한 가장 최근 루틴이다.
- **조기 기록**: 7일 전에 루틴을 바꾸며 선택적으로 남긴 낮은 신뢰도의 결과다.
- **Rescue**: 불편을 대화로 정리하고 확인 순위와 다음 루틴을 제안하는 흐름이다.

## 반드시 지킬 규칙

1. 제품 등록은 현재 루틴을 자동으로 바꾸지 않는다.
2. 루틴의 제품·순서·시간대·빈도 변경은 항상 새 버전을 만든다.
3. 새 루틴은 DAY 1부터 7일을 시작한다. DAY 7 00:00에 앱 안에서 결과를 묻는다.
4. 7일은 안전·효능 기준이 아니다. 불편은 즉시 Rescue로 들어간다.
5. 실제 사용이 기록과 다르면 해당 버전을 안정으로 승급하지 않는다.
6. 불편 없음은 루틴 전체의 관찰이지 각 제품의 단독 적합 판정이 아니다.
7. Rescue가 만든 루틴도 일반 루틴과 같은 새 버전이며 별도 `복구 중` 상태를 두지 않는다.
8. 사용자가 적용하기 전에는 AI가 제품을 삭제하거나 루틴을 바꾸지 않는다.
9. 제품 의견과 추천은 구매 맥락의 설명이다. 잘 맞음, 안전, 효능을 보장하지 않는다.
10. 정보 부족은 `없음`으로 바꾸지 않는다.
11. `잘 모르겠어요`는 모든 AI 질문에서 유효한 답이다. AI는 더 쉬운 관찰 질문을 한 번 제안하거나 정보 부족으로 남기며, 사용자가 모르는 사실을 추정해 채우지 않는다.

## AI와 서버

| AI | 서버 |
| --- | --- |
| 자연어를 이해하고 필요한 후속 질문을 한다. | 인증, 소유권과 상태 전이를 결정한다. |
| 현재 질문에 필요한 외부 근거를 검색한다. | 제품 ID·버전과 출처를 검증한다. |
| 제품 의견, 추천, 루틴과 Rescue를 설명·제안한다. | 현재·안정 루틴과 버전 차이를 계산한다. |
| 자유 문장의 개인 맥락을 기억한다. | 구조화된 이력과 사용자의 확정 행동을 저장한다. |

AI에게 모든 피부 상태를 enum으로 제한하지 않는다. 대신 요청마다 질문, 제품 버전, 현재 루틴, 안정 루틴, 관련 과거 기록과 자연어 맥락을 제공하고 결과를 schema로 받는다. 서버는 그 결과가 실제 데이터와 허용된 행동만 참조하는지 검사한다.

사용자가 `잘 모르겠어요`라고 답하면 AI는 현재 판단을 실제로 바꿀 수 있고 더 쉽게 답할 수 있는 관찰 질문이 있을 때만 한 번 바꿔 묻는다. 예를 들어 피부 유형을 다시 고르게 하지 않고 `바른 뒤 당기거나 답답했던 적이 있나요?`처럼 사용자가 겪은 사실을 묻는다. 다시 모르겠다고 하거나 답이 없어도 흐름을 막지 않고 해당 맥락을 `정보 부족`으로 표시한다.

## 근거 표현

- `제품 공식 정보`: 해당 버전의 제조사·브랜드 원문
- `완제품 연구`: 같은 완제품을 사람에게 사용한 연구
- `원료 연구`: 관련 성분이나 원료에 대한 연구. 완제품 효과로 확대하지 않는다.
- `개인 기록`: 사용자의 특정 루틴 버전과 실제 응답
- `AI 해석`: 위 사실을 현재 질문에 연결한 설명
- `정보 부족`: 버전·원문·연구·개인 기록이 없거나 서로 충돌하는 상태

각 중요한 주장에는 위 근거 종류와 원문 링크 또는 내부 기록 참조가 있어야 한다.

## 의료 경계

- 특정 제품을 원인·범인으로 확정하지 않는다.
- 피부 질환, 알레르기, 응급도와 진료과를 판단하지 않는다.
- 사용자가 심각하거나 빠르게 악화된다고 말하면 제품 순위를 중단하고 전문가 확인을 제안한다.
- 안정 루틴이 없더라도 개인 기록으로 보수적인 최소 루틴을 제안할 수 있지만 기준점이 약함을 명시한다.
- 루틴이 전혀 없으면 제품 순위를 만들지 않는다.

## 데이터 범위

- 국내 판매 스킨케어, 클렌징, 선케어만 다룬다.
- 카탈로그 버전이 불확실하면 등록과 실제 루틴 기록은 허용하지만, 해당 제품의 성분·기능·사용법을 AI 판단 근거로 쓰지 않는다.
- 가격·판매처는 참고 정보이며 판단 입력이 아니다.
- 제품 메모는 사용자가 요청한 AI 작업에만 전달한다.
- 영수증 원본은 MVP에서 영구 보관하고 계정 영구 삭제 시 함께 삭제한다.
