# SKN

> 써본 만큼, 나를 더 잘 알게 되는 스킨케어 경험 아카이브

화장품을 자주 탐색하는 사람은 제품을 많이 써도 지난 사용감, 조합과 피부 반응을 대부분 기억에만 남긴다. SKN은 그 경험을 제품·루틴·시점과 연결해 보존하고, AI가 반복된 선호와 패턴을 원본 기록과 함께 다시 찾아 다음 탐색에 쓰게 한다.

[프로토타입](https://sksksksksksss.github.io/skn-app/prototype/) · [사용자 흐름](https://sksksksksksss.github.io/skn-app/flow/) · [API](https://sksksksksksss.github.io/skn-app/api/) · [작업판](https://github.com/orgs/sksksksksksss/projects/2)

## 한 바퀴

```text
제품을 탐색한다
→ 실제 제품과 루틴을 함께 기록한다
→ 사용 중 또는 7일 뒤 경험을 돌아본다
→ AI가 과거 경험과 연결해 패턴을 보여준다
→ 그 패턴을 다음 제품 탐색과 불편 대응에 다시 쓴다
```

핵심은 AI가 사용자를 대신 판정하는 것이 아니다. 사용자가 계속 경험하고, SKN이 그 경험을 잃지 않게 연결하며, 사용자가 자기 취향과 사용 패턴을 발견하게 하는 것이다.

## 이번 P0

- 제품명으로 내 화장품을 등록한다.
- 제품·아침/저녁·순서·빈도가 포함된 실제 루틴을 저장한다.
- 제품 하나 또는 루틴 전체의 사용 경험을 자연어로 남긴다.
- 7일은 안전 심사가 아니라 기억을 돌아보는 기본 시점으로 쓴다.
- AI가 과거 기록을 연결해 패턴과 불확실성을 원본 근거와 함께 보여준다.
- 궁금한 제품을 제품 정보와 내 경험에 비교한다.
- 불편함이 포함되면 같은 AI 채팅에서 변경점과 다음 루틴을 확인한다.

영수증 OCR, 가격·판매처, 푸시 알림과 정교한 전체 카탈로그는 P1·P2다. 우선순위는 [요구사항](./docs/04-requirements/README.md)과 [작업 계획](./docs/03-delivery-plan.md)을 따른다.

## AI의 역할

| AI가 하는 일 | 시스템이 보장하는 일 |
| --- | --- |
| 자연어 경험에서 사용자가 말한 표현을 정리한다. | 원문과 제품·루틴·시점을 연결해 보존한다. |
| 관련 과거 경험과 확인된 제품 정보를 찾는다. | 다른 사용자의 기록을 섞지 않고 실제 ID와 버전을 검증한다. |
| 반복된 선호·사용 패턴과 반대 기록을 설명한다. | 근거 수, 원본 참조, 불확실성과 모델 버전을 저장한다. |
| 불편 대화에서 필요한 질문과 다음 루틴을 제안한다. | 진단·원인 확정을 막고 사용자 승인 전 상태를 바꾸지 않는다. |

## 제품 경계

- 피부 질환, 알레르기, 원인과 응급도를 진단하지 않는다.
- 개인 패턴을 피부 타입이나 영구적인 성향으로 단정하지 않는다.
- 제품의 피부 적합성·안전·효능을 보장하지 않는다.
- 정보가 없는 것을 `없음`이라고 표현하지 않는다.
- AI 요약은 사용자 원문을 대체하지 않는다.
- 가격·인기·제휴 수수료로 탐색 결과를 바꾸지 않는다.
